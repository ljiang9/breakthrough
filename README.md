# breakthrough（突破棋）

极简突破棋（Breakthrough）引擎：8×8 棋盘，每方 16 个兵，只能向前走一格、
向前斜一格吃子，第一个把兵送到对方底线者获胜。纯 Python 标准库。

## 玩法

- 黑方 `●` 从上往下走（第 0–1 行开局），白方 `○` 从下往上走（第 6–7 行开局）
- 走法：向前一格（前方必须为空）；向前斜一格**只能吃子**，不能空走
- 先到对方底线（黑到第 7 行 / 白到第 0 行）即获胜
- 交互走法格式：`1,3-2,3`（起点-终点），`q` 退出

## 用法

```bash
python3 -m breakthrough                 # 人机/双人回合制（需要终端）
python3 -m breakthrough --auto         # AI 对 AI 自动演示
python3 -m breakthrough --auto --games 20 --seed 7 --verbose
```

## AI 说明

贪心评估函数：子力 + 推进进度 + 临门一脚加成 − 被吃威胁；即胜走法必走。
不是精确求解（8×8 全搜索太大），人类熟悉后通常能赢。

## 已知局限（诚实版）

- AI 只是贪心评估，不做深层搜索；残局长捉/反复横跳靠 400 手上限判和棋兜底
- 只有 8×8 标准规则，无变体棋盘
- 文本棋盘，无图形界面/存档/悔棋；Python 3.10+
